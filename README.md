# KB&YA — Portfolio vidéo

Portfolio de Yonathan Andreu : réalisateur, caméraman, monteur et créateur vidéo IA à Jérusalem.

## Développement

```bash
npm install
npm run dev
```

## Déploiement Render

Le fichier `render.yaml` configure automatiquement un site statique React sur l'offre gratuite Render.
